# Workspace Rules & Guidelines

## Documentation & README Maintenance Rule
- **Always Keep `README.md` Up To Date**: Whenever modifying, creating, or refactoring smart contracts, frontend modules, deployment scripts, or configuration files in this repository, ALWAYS update both the repository root `README.md` (`docs.nervos.org/README.md`) and component `README.md` files to accurately reflect the changes, architecture, script parameters, and workflow steps.
